     UX Enhancement Suggestion: Add Deletion Capability for Captured Screenshots

     Type: Feature Request / Enhancement

     Description: Currently, if the agent background tracker captures a screen
     containing sensitive data (such as personal banking information, corporate
     passwords, or private messages), the entry remains permanent. Users must
     either leave it exposed or request a database wipe from system administrators.

     Proposed Solution: Introduce a Trash Can "Delete" icon on the card overlay during
     mouse hovers, as well as an explicit action button within the expanded full-screen
     preview player. This allows swift removal of compromised image assets. To maintain
     organizational accountability, completing a deletion can automatically deduct the
     associated timeline block (e.g., 10 minutes) from the user's daily total tracked
     work hours.

     Reference Module: Screenshots Management Page

     Proof: https://go.screenpal.com/watch/cO1FXGnuER5                                                                            Implemented (Done)


     UX Enhancement Suggestion: Add Inline Editing Capability for Pending Leave
     Requests

     Type: Feature Request / Enhancement

     Description: Currently, if a user selects the wrong leave type (e.g., choosing "Sick"
     instead of "Casual"), they must delete the row entirely or await rejection and
     create a new request.

     Proposed Solution: Introduce a pencil "Edit" icon next to the action controls strictly for
     entries that are still in a pending status. This allows quick changes to the leave type
     or date boundaries without forcing a total deletion cycle.

     Reference Module: Leave Management Page
